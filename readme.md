# Jardins Replay
Ideia inicial --> Sistema para captura e disponibilização de lances das partidas de futebol.

--> Quando um jogador aperta o botão a camêra salva os últimos 30 segundos de gravação para que o usuário possa comprar as imagens depois 

--> Sistema vai possibilitar com que o usuário resgate os lances ao qual apertou o botão.
